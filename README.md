## 👤 Author

## 📌 Overview
This project extracts text from images (receipts/documents) using OCR techniques.  
It uses **Tesseract** and **EasyOCR** along with **OpenCV preprocessing** to improve accuracy.

---

## 🎯 Features
- Extract text from images  
- Use Tesseract OCR  
- Use EasyOCR  
- Apply image preprocessing (OpenCV)  
- Compare OCR results before and after preprocessing  
- Extract receipt details (date, total, items)  

---

## 🛠️ Tools & Libraries
- Python  
- OpenCV  
- pytesseract  
- EasyOCR  
- NumPy  
- Pandas  
- Matplotlib
